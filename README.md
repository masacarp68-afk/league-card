# 順位表 画像ジェネレーター

Google スプレッドシートの順位表をコピペするだけで、X（旧Twitter）投稿用の順位表画像（1920×1080 PNG）を作るツールです。ログイン不要・サーバー不要。リーグ戦・雀竜位戦・フレッシュスターカップに対応。

## 使い方

まず上部の **リーグ戦／雀竜位戦／フレッシュスターカップ** を選びます（設定はそれぞれ別に記憶されます）。

1. スプレッドシートで「順位／組／登録名／トータル／対局数」の **見出し行を含めて** 選手の最終行まで範囲選択し、コピー
2. ページの「貼り付け」欄に Ctrl+V → すぐにプレビューが出ます
3. 設定を入力（次回も覚えています）
   - **タイトル**：`第25期 日本プロ麻雀協会 後期【E3】リーグ` のように書くと、**最後のスペースより前**（`第25期 日本プロ麻雀協会`）が小さく、後ろ（`後期 E3 リーグ`）が大きく表示され、`【 】` で囲んだ部分が金色になります
   - **節**、**全節数**、**全回戦数**（フッターの「全12節・48回戦」と各選手の `20/48` に使用）
   - **昇級（上位から）**：金／銀／銅 の順にグループの人数。2・3段階昇級のあるリーグは上のグループから順に入力（1段階だけなら金だけ）
   - **降級（下位から）**：赤／薄赤 の順にグループの人数。途中足切りなど2段階あるときは最下位側を赤に（1段階だけなら赤だけ）
   - **テーマ**（ネイビー／えんじ／ピンク／深緑／パープル／ブラック）と **テーマ色**（自由な色にしたいとき）。地色とカードの色が変わります
   - **対局数を表示**：OFF にすると名前の幅が広がります（人数が多いとき用）
4. **画像をコピー** → X の投稿欄に Ctrl+V。または **ダウンロード** で PNG を保存

- 列は見出し名で自動判定します（名前: 登録名/選手名/氏名、pt: トータル/合計/累計、対局数: 対局数/試合数）。「組」など他の列は無視されます
- 「順位」列が無ければ貼った順に 1 から番号を振ります
- 縦11行まで詰めて、超えたら列を増やします（33人以下は3列、77人なら7列）。カードが横長のとき（3列など）は「名前 … pt」の1行組み、人数が多くカードが狭いときは名前の下に pt を置く2行組みに自動で切り替わります。1〜3位は金・銀・銅の丸、pt はプラス緑・マイナス赤・0 は `±0.0`

## 雀竜位戦

1. スプレッドシートで「登録名／ポイント」の **見出し行を含めて** 選手の最終行まで範囲選択し、コピー（各回戦の「得失点／順位／合計点」の列が混ざっていて構いません）
2. 貼り付けると **ポイントの高い順に並べ替えて順位を付けます**（同点は同順位）。各回戦の「順位」（着順）は無視します
3. 対局数は「得失点」に数値が入っている回戦の数です。「全回戦数」を 6 にすると `5/6` のように出ます
4. 色分けは「通過（上位から）」「敗退（下位から）」に人数を入れます。「全節数」を 0 にするとフッターは「全6回戦」だけになります
5. 「供託」「check sum」の行は自動で読み飛ばします

## フレッシュスターカップ

1. スプレッドシートで「順位／氏名／入会期／合計」の **見出し行を含めて** 選手の最終行まで範囲選択し、コピー（1回戦〜決勝の列が混ざっていて構いません）
2. 順位はシートの「順位」列を **そのまま** 使います（決勝の結果順なので並べ替えません。無ければ貼った順）
3. 名前の右に入会期（`6期生`）を小さく表示します
4. 対局数は 1回戦〜決勝に数値が入っている数です。「全回戦数」を 5 にすると `5/5`・`3/5` のように出ます
5. 色分けは「入賞（上位から）」に人数を入れます（初期値は 金1・銀1・銅1 ＝ 優勝／準優勝／3位）
6. 右上のロゴはこのモードだけ `assets/logo-freshstar.png` になります

## ロゴ

`assets/logo.webp`（または `logo.png` / `logo.jpg`）を右上に表示します（フレッシュスターカップは `assets/logo-freshstar.png`）。差し替えるときはファイルを上書きしてください。ほぼ正方形のロゴは白い丸に、横長のロゴは白い角丸プレートに載せます。

## 開発

```bash
npm test
```

ローカル確認:

```bash
npx serve .
```

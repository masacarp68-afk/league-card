# 順位表 画像ジェネレーター

Google スプレッドシートの順位表をコピペするだけで、X（旧Twitter）投稿用の順位表画像（1920×1080 PNG）を作るツールです。ログイン不要・サーバー不要。リーグ戦と雀竜位戦に対応。

## 使い方

まず上部の **リーグ戦／雀竜位戦** を選びます（設定はそれぞれ別に記憶されます）。

1. スプレッドシートで「順位／組／登録名／トータル／対局数」の **見出し行を含めて** 選手の最終行まで範囲選択し、コピー
2. ページの「貼り付け」欄に Ctrl+V → すぐにプレビューが出ます
3. 設定を入力（次回も覚えています）
   - **タイトル**：`第24期 雀王戦【A2】リーグ` のように `【 】` で囲んだ部分が金色になります
   - **節**、**全節数**、**全回戦数**（フッターの「全12節・48回戦」と各選手の `20/48` に使用）
   - **昇級（上位から）**：金／銀／銅 の順にグループの人数。2・3段階昇級のあるリーグは上のグループから順に入力（1段階だけなら金だけ）
   - **降級（下位から）**：赤／薄赤 の順にグループの人数。途中足切りなど2段階あるときは最下位側を赤に（1段階だけなら赤だけ）
   - **テーマ**（星空ネイビー／えんじ／深緑／パープル／ブラック）と **テーマ色**（自由な色にしたいとき）
   - **対局数を表示**：OFF にすると名前の幅が広がります（人数が多いとき用）
4. **画像をコピー** → X の投稿欄に Ctrl+V。または **ダウンロード** で PNG を保存

- 列は見出し名で自動判定します（名前: 登録名/選手名/氏名、pt: トータル/合計/累計、対局数: 対局数/試合数）。「組」など他の列は無視されます
- 「順位」列が無ければ貼った順に 1 から番号を振ります
- 26人以下は3列、27〜48人は4列、49人以上は5列で自動整列します

## 雀竜位戦

1. スプレッドシートで「登録名／ポイント」の **見出し行を含めて** 選手の最終行まで範囲選択し、コピー（各回戦の「得失点／順位／合計点」の列が混ざっていて構いません）
2. 貼り付けると **ポイントの高い順に並べ替えて順位を付けます**（同点は同順位）。各回戦の「順位」（着順）は無視します
3. 対局数は「得失点」に数値が入っている回戦の数です。「全回戦数」を 6 にすると `5/6` のように出ます
4. 色分けは「通過（上位から）」「敗退（下位から）」に人数を入れます。「全節数」を 0 にするとフッターは「全6回戦」だけになります
5. 「供託」「check sum」の行は自動で読み飛ばします

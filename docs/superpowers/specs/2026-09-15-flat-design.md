# 画像デザインの置き換え（フラット・2行カード）

見本画像に寄せて、`js/render.js` の描画を「星空＋1行カード」から「黒に近いフラットな地＋2行カード」に置き換える。
パーサー・画面・設定項目は変えない（旧デザインは残さない）。

## 画像仕様（1920×1080）

- **背景**：ほぼ黒のフラット。テーマ色をごく薄く混ぜる（星・光のグラデーションは廃止）
  - テーマ色から 地色 / カード / 順位の丸 の3色を作る（`palette`）
- **ヘッダー**
  - 左：タイトル。**最後のスペース（半角・全角）より前を小さく（0.66倍・太字）、後ろを大きく（極太）**。スペースが無ければ全部大きく（`splitTitleSized`）
    `【 】` で囲んだ部分は金色で、左右に少し間を空ける
  - 右：節（`第1節`）を**金の角丸バッジ**（黒文字）。その右に**白い丸**の中にロゴ（丸に内接する正方形に収める）
  - 下に金の細いライン（3px）
- **カード**（角丸 8px、テーマ色ベースの濃い地）
  - 左に順位の丸。**1〜3位は金・銀・銅**（黒文字）、それ以外は地色より少し明るい丸に白数字
  - 上段：名前（白・太字）。幅に入らなければ少し小さくし、それでも入らなければ末尾を `…`
  - 下段：pt（極太。プラス緑 `+242.3`／マイナス赤 `▲8.5`／0 は灰 `±0.0`）＋対局数 `4/20`（小さく灰色）
  - 昇級ゾーン：上位から 金→銀→銅 の枠と薄い塗り、名前も同じ色。降級ゾーン：下位から 赤→薄赤 の枠と塗り（名前は白）
- **列数**：縦 11 行まで詰め、超えたら列を増やす（最低 3 列）。`cols = max(3, ceil(n / 11))`
  - 行の高さは上限 104px。文字サイズは行の高さと列幅から自動算出
- **フッター**：右下に「全5節・20回戦」（変更なし）

## 変更点

- `fmtPt(0)` は `+0.0` → `±0.0`
- `layoutFor` は 3/4/5 列固定 → 11 行基準
- 初期タイトルを `第○期 日本プロ麻雀協会 【A○】リーグ`（スペース区切り）に
- テーマ名「星空ネイビー」→「ネイビー」

## テスト

- `test/render.test.js`：`fmtPt` の `±0.0`、`layoutFor` の 11 行基準、`splitTitleSized` の分割（半角・全角スペース、スペース無し、空）
- 描画は 77 人（見本と同じ）と 22 人（金1・銀2／赤4・薄赤2）をブラウザで目視確認

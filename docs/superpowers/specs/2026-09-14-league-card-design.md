# リーグ順位表 画像ジェネレーター 設計

日本プロ麻雀協会のリーグ戦成績を X（旧Twitter）に投稿するための順位表画像を、
Google スプレッドシートからのコピペだけで生成する静的 Web ツール。

## 目的・前提

- 現状は「HP 見てね」＋リンクのみ。X では画像があった方が見られるので、毎節の投稿用に順位表画像を作りたい
- スプレッドシートは HP と連携済みで手元にある。そこから範囲選択→コピー→貼り付けで画像になれば十分
- 選手写真は扱わない。「今節対局した人」の強調も不要

## 構成

- 新規リポジトリ `league-card`。GitHub Pages（`main` ブランチのルート）で公開
- 依存ライブラリなし。静的ファイルのみ
  - `index.html` … 画面（貼り付け欄・設定欄・プレビュー・ボタン）
  - `style.css` … 画面の見た目
  - `js/parse.js` … TSV パーサー（純粋関数。Node でテスト可能）
  - `js/render.js` … Canvas 描画（`renderStandings(data, settings) → HTMLCanvasElement`）
  - `js/app.js` … 画面のつなぎ（貼り付け→パース→描画、設定の保存、コピー／ダウンロード）
  - `test/parse.test.js` … `node --test`
- フォントは Google Fonts（Noto Sans JP）。描画前に `document.fonts.load` で読み込みを待つ

## 入力（スプレッドシートからのコピー）

見出し行を含めて「順位／組／登録名／トータル／対局数」の範囲を選択してコピーする。
クリップボードの内容は TSV（タブ区切り・改行区切り）として扱う。

### 列の判定（見出し名・正規表現）

| 役割 | 見出しの判定 | 必須 |
|---|---|---|
| 名前 | `登録名` `選手名` `氏名` `名前` を含む | 必須 |
| トータル pt | `トータル` `合計` `累計` `ポイント` を含む | 必須 |
| 対局数 | `対局数` `試合数` `回戦` を含む | 任意（無ければ `[n/N]` を表示しない） |
| 順位 | `順位` を含む、または見出しが空で列の中身が連番 | 任意（無ければ貼った順に 1 から採番） |

- それ以外の列（組 など）は無視する
- 数値は `,` `+` 空白を除去し、全角マイナス（`－` `−`）と `▲` は負号として扱う
- 名前が空、または pt が数値にならない行はスキップ
- 必須列が見つからない場合はエラーメッセージを表示（「見出し行を含めてコピーしてください」）

### パーサーの出力

```js
{ players: [ { rank: 1, name: '宇野 公介', total: 374.9, games: 32 }, ... ] }
```

## 設定（画面の入力欄・localStorage に保存）

| 項目 | 例 | 用途 |
|---|---|---|
| タイトル | 第51期 日本プロ麻雀協会 A2リーグ | ヘッダー |
| 節 | 第9節 | ヘッダー右側 |
| 全節数 | 12 | フッター「全12節・48回戦」 |
| 全回戦数 | 48 | フッター、各選手の `[32/48]` |
| 昇級 上位○名 | 3 | 順位バッジを青にする人数 |
| 降級 下位○名 | 8 | 順位バッジをグレーにする人数 |
| テーマ色 | `#7a1f2b`（えんじ） | 背景 |

## 画像仕様

- 1600×900 px（16:9）PNG
- 背景：テーマ色。右側に少し明るい斜めの帯（見本と同じ雰囲気）
- ヘッダー：タイトル（白・太字）＋節（白）。左上
- 本体：順位バッジ＋白カード（名前／pt／`[対局数/全回戦数]`）を縦に並べ、列で折り返す
  - 24人以下 → 3列、25人以上 → 4列
  - 行数 = ceil(人数 ÷ 列数)。行の高さとフォントサイズは行数から自動算出
  - バッジ色：昇級＝青 `#1e63c8`、残留＝オレンジ `#e8781e`、降級＝グレー `#6b6b6b`
  - pt は符号付き `+374.9` / `-14.7`（小数1桁）。名前が長い場合は末尾を `…` で省略
- フッター：右下に「全12節・48回戦」

## 出力

- **画像をコピー**：`navigator.clipboard.write` で PNG をクリップボードへ（X の投稿欄に Ctrl+V で貼れる）。非対応ブラウザではボタンを無効にして理由を表示
- **ダウンロード**：`<a download>` で `league-card.png` を保存
- プレビュー：Canvas をそのまま画面に表示（CSS で縮小）

## 画面の流れ

1. ページを開く → 前回の設定が入力欄に復元される
2. 貼り付け欄（textarea）に Ctrl+V → `input` イベントでパース → 即プレビュー更新
3. 設定を変えても即プレビュー更新
4. コピー or ダウンロード

## エラー処理

- 貼り付け内容が空／見出しが見つからない／選手が0人 → プレビューの代わりにメッセージ表示
- フォント読み込み失敗 → システムフォントで描画（例外にしない）
- クリップボード書き込み失敗 → ダウンロードを案内するメッセージ

## テスト

- `test/parse.test.js`：列の自動判定、見出しの揺れ、数値変換（カンマ・全角マイナス・▲）、空行スキップ、順位列なしの採番、必須列なしのエラー
- 描画はブラウザで実際にサンプル（22人）を貼って目視確認

## やらないこと

- 選手写真
- 今節対局者の強調（黄緑）
- スプレッドシート API 連携（コピペのみ）
